# wagli — versão de demonstração

Build estático (sem servidor) da wagli, publicado para testar a experiência no celular.

- Funciona: página inicial, planos, perguntas e o mapa de exemplo (`/@demo`).
- Não funciona aqui: candidatura, login, painel e estúdio (dependem do servidor).
- Os lugares e os nomes do mapa de exemplo são fictícios.
- Fotos de lugares: Wikimedia Commons, com créditos em `creditos-fotos.txt`.
- Mapas: OpenFreeMap, dados © colaboradores do OpenStreetMap.
